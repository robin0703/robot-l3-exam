电学基础

理论考试的"大头"，单选、判断题最爱考这些概念，先理解再记忆！

🧲 电荷与摩擦起电

  • 摩擦起电：用摩擦的方法使两个不同的物体带电
  • 物体带电的方法：摩擦起电、接触带电、感应起电
  • 正电荷：丝绸摩擦过的玻璃棒
  • 负电荷：毛皮摩擦过的橡胶棒
  • 同种电荷相互排斥，异种电荷相互吸引
  • 电荷的多少叫电荷量，单位：库伦（库，C）

🪵 导体与绝缘体

  • 导体（善于导电）：金属、人体、大地、石墨、酸碱盐溶液、湿木
  • 绝缘体（不善于导电）：干木、陶瓷、玻璃、橡胶、油、塑料
  • 物质按导电性还可分为：导体、绝缘体、半导体、超导体
⚠️ 易错潮湿的木头、雨水会导电，是导体；干燥的木棍才是绝缘体！

🔋 电流、电压、电阻

  • 电流 I：电荷的定向移动形成电流，单位安培（A）
  • 电压 U：单位伏特（V），由电源提供
  • 电阻 R：单位欧姆（Ω），表示导体对电流的阻碍作用
  • 电流方向 = 正电荷定向移动的方向
  • 在电源外部，电流从正极流向负极
⚠️ 易错电流方向与电子（负电荷）移动方向相反！电阻是导体本身的性质，电压为 0 时电阻不为 0。

📐 欧姆定律

导体中的电流，跟电压成正比，跟电阻成反比。

I = U ÷ R
  • 电压越大 → 电流越大；电阻越大 → 电流越小

🔀 电路的三种状态

  • 通路：处处连通，有电流通过 ✅
  • 断路（开路）：电路断开，没有电流 ⛔
  • 短路：导线直接接通电源两极，电流很大，可能烧坏电源，绝对不允许 🔥
⚠️ 易错短路不是正常的电路状态！

🧩 电路的组成与电流条件

  • 基础电路四要素：电源、用电器、开关、导线（电压表不是必要元素）
  • 电流产生三条件：① 有自由电荷 ② 导体两端有电压差 ③ 形成闭合回路
  • 电路搭设时不能带电插拔元器件

📏 电流表与电压表

  • 测电流：电流表 串联 在电路中
  • 测电压：电压表 并联 在用电器两端
🎵 口诀"流串压并" —— 电流表串联，电压表并联。

🔋 电池与安全电压

  • 1 节干电池 = 1.5V；两节串联 = 3V（电压相加）
  • 两节并联 = 仍是 1.5V（电压不变）
  • 我国家庭电路电压：220V
  • 人体安全电压：一般不高于 36V

⚖️ 串联 vs 并联（必考对比）

对比项串联电路并联电路
回路只有一条回路，无分支有多条回路（支路）
电流处处相等干路电流 = 各支路电流之和
电压总电压 = 各用电器电压之和（分压）各支路电压相等
互相影响一处断开，整个电路都断一条支路断开，不影响其他支路
生活例子节日小彩灯家用电器（电灯、冰箱、电脑）都是并联
🎵 口诀"串联电流处处等，并联电压处处等；串联一断全都断，并联各干各的活。"

📝 典型真题

单选 · 电流概念

下列关于电的描述不正确的是（　）

A. 电荷发生定向移动形成电流B. 电源是形成电流的条件之一C. 在电源的外部，电流从正极流向负极D. 电流的移动方向与电子的移动方向相同
答案：D
电流方向规定为正电荷定向移动的方向，电子带负电，所以电流方向与电子移动方向相反。
单选 · 串并联

以下对并联电路的叙述错误的是（　）

A. 并联电路有多个回路B. 并联电路干路电流等于各支路电流之和C. 并联电路中如果有一处支路断开，整个电路都断开D. 并联电路中总电阻小于各支路电阻
答案：C
并联电路各支路互不影响，一条支路断开，其他支路照常工作。"一断全断"是串联的特点。
单选 · 电阻性质

下列关于电阻叙述正确的是（　）

A. 电路两端的电压越大，电阻就越大B. 通过导体的电流减小，电阻就增大C. 导体的电阻跟电压成正比，跟电流成反比D. 电阻表示导体对电流阻碍的性质，不随电压、电流的改变而改变
答案：D
电阻是导体本身的性质（由材料、长度、粗细决定），电压电流怎么变，电阻都不变。

电子元器件

认识这些"小零件"的脾气，电路题和实操题都少不了它们。

➡️ 二极管

  • 加正向电压才导通，加反向电压就截止 —— 这叫单向导电性
  • 理想二极管：正向电阻 ≈ 0，反向电阻 = 无穷大
  • 属于半导体元器件

💡 LED（发光二极管）

  • 中文名"发光二极管"，是半导体元器件，单向导通
  • 区分极性：长脚是正极，短脚是负极
  • 直径 10mm 的 LED 工作电压约 1.7V ~ 3V
  • 直接接主控板（5V）针脚时，要串联一个电阻分压，否则容易烧坏
⚠️ 易错"LED 不区分极性"是错误说法，考试常考！

🔺 三极管

  • 主要作用：放大电流
  • 也可当作电子开关使用

🎛️ 电位器

  • 本质是一个可变电阻，旋转旋钮改变阻值
  • 接模拟输入口，返回值范围 0 ~ 1023
  • 实操"常客"：控制 LED 亮度、舵机角度、蜂鸣器频率

🔋 电源标识

  • 常见电源符号标识：+、V、VCC、VEE
  • GND 表示接地（负极）

🐝 蜂鸣器 & 舵机

  • 蜂鸣器：发声的执行器，可以设定发声频率
  • 舵机：可以转到指定角度（0°~180°）的执行器
  • 它们都是执行器，不是传感器

🔣 常见电路符号（考试会认图）

电源（电池）
长线正极，短线负极
电阻

单选 · LED 特性

以下对 LED 的叙述错误的是（　）

A. LED 是一种半导体元器件B. LED 不区分极性C. LED 是单向导通的D. LED 中文称为发光二极管
答案：B
LED 是二极管的一种，区分正负极（长正短负），接反了不亮。
单选 · 电路必要元素

以下电路组成元素中，不属于必要元素的是（　）

A. 电源B. 用电器C. 开关D. 电压表
答案：D
基础电路只需要电源、用电器、开关、导线四样，电压表只是测量工具。

Arduino UNO 编程知识

三级考试的核心主控板，理论 + 实操都围绕它出题。

🧠 认识主控板

  • 型号：Arduino UNO / Nano，相当于机器人的大脑
  • 处理器：ATmega328P，主频 16MHz
  • 工作电压：5V
  • 存储设备：SRAM、Flash、EEPROM（CPU、GPIO 不是存储设备）
  • Arduino 是开源软硬件平台，源于意大利，主控板有多种型号

📍 引脚（管脚）

  • 数字引脚：0 ~ 13 号，可设输入或输出模式
  • 模拟输入引脚：A0 ~ A5（也能当数字引脚用）
  • 支持 PWM 的引脚：3、5、6、9、10、11（板上有 ~ 标识）
  • 数字输入三种模式：输入、输出、内部上拉输入
🎵 口诀PWM 六兄弟：3、5、6、9、10、11。

〰️ 电平与信号

  • 低电平：-0.5V ~ 1.5V，用 0 表示
  • 高电平：3.5V ~ 5.5V，用 1 表示
  • 介于两者之间 → 信号不稳定（0 和 1 乱跳）
  • 数字信号：只有 0 / 1 两种（如按键）
  • 模拟输入：连续变化，范围 0 ~ 1023（如电位器、光敏电阻）
  • 模拟输出（PWM）：范围 0 ~ 255

🌊 PWM 是什么

  • PWM：在数字系统中，通过调整占空比来实现"模拟输出"的效果
  • 占空比越大，等效电压越高（50% ≈ 2.5V）
  • 应用：LED 调亮度、呼吸灯、电机调速
⚠️ 易错PWM 是"模拟输出"，A0~A5 才是模拟输入，别搞反！

🏗️ 三种程序结构

  • 顺序结构：从上往下依次执行
  • 选择结构：如果……就……（如果 / 否则如果 / 否则）
  • 循环结构：重复执行（重复执行、循环 n 次、当满足条件时循环）

🔣 流程图符号（必考认图）

  • 圆角矩形 ＝ 开始 / 结束
  • 平行四边形 ＝ 输入 / 输出
  • 矩形 ＝ 处理（计算、赋值）
  • 菱形 ＝ 判断（是 / 否分支）
  • 箭头 ＝ 流程线
🎵 口诀"圆角开始平行四边读，矩形干活菱形问。"

📦 数据类型

  • 布尔型：0 或 1（1 字节）
  • 字符型：-128 ~ 127（1 字节）
  • 字节型：0 ~ 255（1 字节）
  • 整型：2 字节　长整型：4 字节
  • ASCII 码：小写 a = 97（把字符存进整型变量，打印出来是数字）

🔧 常用编程模块

  • 数字输入：读按键等，返回 0 / 1
  • 数字输出：设为高 / 低电平，控制 LED 亮灭
  • 模拟输入：读电位器、光敏等，返回 0~1023
  • 模拟输出：PWM 输出 0~255，调亮度
  • 映射：把一个范围换算成另一个范围（如 0~1023 → 0~255）
  • 约束：把数值限制在最小值和最大值之间
  • 串口监视器：Serial 打印，用来查看传感器的值、调试程序

➕ 变量与逻辑运算

  • 变量是"存数据的小盒子"，程序运行中值可以改变
  • 逻辑与 &&：两个条件都成立才为真
  • 逻辑或 ||：任意一个成立就为真
  • 逻辑非 !：真假颠倒
  • 判断条件中，真 = 1，假 = 0

🎚️ 上拉 / 下拉电阻（老师补充讲解点）

  • 按键没按下时，引脚"悬空"，读数会乱跳
  • 上拉电阻：把引脚默认"拉"到高电平（1）
  • 下拉电阻：把引脚默认"拉"到低电平（0）
  • 作用：让按键输入稳定可靠，不受干扰

🦾 舵机小知识

  • 舵机角度范围：0° ~ 180°
  • 舵机不是只能接 PWM 引脚（普通数字引脚也可以）
  • 电位器（0~1023）→ 映射 → 舵机角度（0~180）是经典考法

🔡 ASCII 码速查表

电脑里每个字符都对应一个数字，这个数字就是 ASCII 码。只要记住三个"起点"，其他都能推出来 👇

字符ASCII 码规律
0（数字零）48数字的起点
1 ~ 949 ~ 57在 48 的基础上依次 +1
A（大写）65大写字母的起点
B ~ Z66 ~ 90在 65 的基础上依次 +1
a（小写）⭐97小写字母的起点，真题考过！
b ~ z98 ~ 122在 97 的基础上依次 +1
🎵 口诀"0 是 48，A 是 65，a 是 97"——小写比大写大 32（a − A = 32）。

📝 典型真题

单选 · 数据类型 / ASCII

变量声明中将字符 a 赋值给整型变量 c，通过串口监视器打印 c，看到的可能是（　）

答案：C
字符在电脑里用 ASCII 码保存，小写 a 的 ASCII 码是 97，整型变量打印出来就是数字 97。

A. -128B. 256C. -52D. 1024
答案：B
模拟输入的范围是 0 ~ 1023，四个选项里只有 256 在这个范围内（1024 超界了）。
单选 · 主控板参数

Arduino UNO 主控板采用 ATmega328P-PU 处理器，该处理器的主频为（　）

A. 4MHzB. 8MHzC. 16MHzD. 32MHz
答案：C
UNO / Nano 的"心跳"是 16MHz，记牢这个数字。

机器人基础

机器人的"身体构造"，常和传感器、执行器一起考。

🦴 机器人四大组成部分

  • 控制器 → 相当于大脑（Arduino 主控板）
  • 传感器 → 相当于眼睛、耳朵等感觉器官
  • 执行器 → 相当于肌肉（舵机、电机、LED、蜂鸣器）
  • 结构体 → 相当于躯干（支架、外壳）

👀 常见传感器（输入）

  • 超声波传感器：测距离，相当于机器人的眼睛
  • 光敏电阻：感知光线强弱（模拟输入）
  • 声音传感器：感知声音（模拟输入）
  • 电位器：旋钮位置（模拟输入）
  • 按键开关：按下 / 松开（数字输入）
  • 红外接收模块：接收遥控器信号

💪 常见执行器（输出）

  • LED 灯 —— 发光
  • 蜂鸣器 —— 发声
  • 舵机 —— 转到指定角度
  • 电机 —— 持续转动
⚠️ 易错按键开关是输入设备（传感器），不是执行器！

💭 关于机器人的说法

  • 机器人 = 控制器 + 执行器 + 传感器 + 结构体 ✅
  • 机器人不一定有人的外形
  • 机器人可以编程控制，也可以遥控
  • 机器人不一定要有人工智能

答案：B
控制板负责"思考"和"发号施令"，相当于机器人的大脑。

器件：Atmega328P 主控板、超声波传感器、LED 灯、蜂鸣器、红外接收套件。

任务：三种工作模式 —— 遥控器按 1＝关闭（LED 灭、蜂鸣器静音）；按 2＝短距离模式（反应距离 5cm）；按 3＝长距离模式（反应距离 10cm）。障碍物进入反应距离内时，LED 闪烁 + 蜂鸣器发声，且越靠近频率越快。

解题关键：用一个变量 mode 保存当前模式（0 / 5 / 10），红外按键切换 mode；超声波测距 dist 与 mode 比较；报警频率用"映射"实现——距离越近，延时越短、频率越高。

2021.6📏 距离指示器

▼

器件：LED 灯模块 2 个（LED_A、LED_B）、超声波传感器 1 个、舵机 1 个。

任务：超声波检测距离，控制舵机角度和 LED 亮灭，并把距离显示在串口监视器。距离 10cm 时舵机 90°、两灯均灭；距离 5cm 时舵机 0°、LED_A 闪烁、LED_B 熄灭；距离变化时舵机角度和灯光跟着渐变。

解题关键：先把距离约束在 5~15 之间，再映射到舵机 0~180°；LED 亮度用映射实现渐变，闪烁用"亮→延时→灭→延时"。

2021.3📡 超声波测距

▼

器件：LED 灯模块 3 个、超声波传感器 1 个。

任务：障碍物距离大于 30cm 时 3 盏灯全灭；距离逐渐接近时，3 盏 LED 灯依次点亮；远离时依次熄灭；距离值显示在串口监视器上。

解题关键：用"如果 / 否则如果"按距离分段（如 >30、20~30、10~20、0~10），每段点亮不同数量的灯。

2020.12💡 被电位器控制的呼吸灯

▼

任务：按下按键后 LED 开始"呼吸"（渐亮再渐暗），电位器控制呼吸的快慢；松开按键，LED 熄灭。

解题关键：两个循环（i 从 0→255 渐亮、255→0 渐暗），循环里随时读取按键，松开就"跳出循环"；电位器的值映射到 10~100 作为延时时间。

2019.12🔴 抢答器

▼

任务：两个按键（选手 1、选手 2）+ 红、黄两盏 LED + 蜂鸣器。开机蜂鸣器响 100 毫秒提示开始；谁先按下按键，对应的灯就亮；两人同时按下则都灭。

解题关键：两个按键值分别存进变量 key01、key02，用"逻辑与 &&"组合判断四种情况（都按 / 1 按 2 没按 / 1 没按 2 按）。

练习题🎚️ 电位器控制 LED 和蜂鸣器

▼

任务：旋转电位器，根据返回值分四档：<5 全部熄灭静音；5~300 黄灯亮；300~800 黄、绿灯亮；800~1023 黄、绿、红灯全亮，且蜂鸣器频率随电位器值变化。

解题关键：经典的"分段判断"题，用 如果 / 否则如果 把 0~1023 切成几段，每段设置不同的灯和声音。
